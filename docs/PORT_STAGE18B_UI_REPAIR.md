# PORT — Stage 18B: UI Repair & Visual Polish

Дата: 2026-10-29. Только локальные изменения в `C:\PORT`, поверх Stage 18 / Gemini.

## Исправления

- Sonic: подходящий широкий кадр выбирается из всей проверенной CMS-галереи,
  а не только из первого изображения шириной от 1440 px. Полноразмерный фон,
  направленный тёмный градиент, связанная композиция названия/описания/загрузки
  и дополнительная обложка. Устранён конфликт `inset`, `top`, `height` и transform,
  из-за которого обложка уходила вниз за пределы hero.
- Без подходящего широкого кадра — строка по высоте содержимого с обложкой.
  В текущих данных Zelda используются кадры 4:3, поэтому показана эта композиция.
  Широкий фон не создаётся из растянутой обложки или выдуманного artwork.
- Основное действие — фирменная фиолетовая кнопка. Рядом остаются версия, размер,
  канал, официальный источник и сообщение текущей загрузки этого проекта.
  Доступность, одобрение, выбор версии и native-only ограничения не изменены.
- Галерея остаётся сразу после hero; просмотрщик, стрелки, Escape и возврат фокуса
  сохранены. Навигация по разделам по-прежнему показывает только существующие данные.
- Каталог: адаптивные широкие карточки, полные обложки на мягком фоне из того же
  изображения, ограниченные размеры и отдельная двухколоночная композиция для двух
  проектов. Поиск, фильтры, избранное, сортировка и пагинация сохранены.
- Home: компактнее hero на невысоких окнах, меньше вертикальных интервалов,
  согласованные поля с поиском, скрыта декоративная кассета sidebar. Верх карточек
  виден на первом экране: browser Y≈541 при 1280×720, Y≈495 при 800×600.
- Повышена контрастность вторичного текста. Пустые Downloads и Settings проверены
  в общей теме. Исправлен reduced-motion дефект Stage 18: глобальное отключение
  transform ломало центрирование диалогов и выводило About за нижнюю границу.
  Теперь отключение анимации сохраняет позиционирование. Проверен solid fallback.

## Данные и происхождение прежних версий

`tests/helpers/stage18-fixture.ts` содержал синтетические версии
`v1.1.0-release` / `v1.2.0-stable`, размеры, требования и описания возможностей.
Именно этот fixture использовался в screenshot suite Stage 18. Импортов этого
fixture в `src/` нет; подмены production-данных в приложении не обнаружено.
Fixture теперь явно маркирован QA в описаниях, версиях и на снимках; неподтверждённые
требования, инструкции и рекламные утверждения удалены. Значения приложения через
хардкод не исправлялись.

Production-конфигурация остаётся API v2 без fallback, фиксированный origin
`https://port-catalog-cms.port-catalog-cms.workers.dev`. Анонимный запрос
`/v2/projects` при этой проверке ответил **HTTP 401**; публичная доступность каталога
не подтверждена и аутентификация не обходилась.

Живой локальный CMS API `https://localhost:8787` ответил `schemaVersion: 2`,
Sonic **v1.0.3**, Zelda **v1.2.2**. В настоящем Tauri данные и изображения получены
через существующий Rust HTTPS QA-транспорт с ранее проверенным локальным сертификатом;
маршрутизация/ответы WebView не подменялись. Версии и размеры на экране совпадают
с ответами. Production origin и CSP не менялись. Соседний `C:\PORT-CMS` не открывался.

Browser: 18 исходных и 18 финальных снимков Home, каталога, Sonic, Zelda, Downloads,
Settings на 800×600, 1280×720, 1600×900. Для честного сравнения обе серии используют
один сохранённый набор реальных локальных CMS-ответов и проверенных изображений.
Это replay, а не live production. Отдельные автоматические UI-тесты используют
явные синтетические fixtures; проверки большого каталога содержат 40 QA-записей,
24 карточки на первой странице и 16 на второй. Фиктивные проекты в PORT не добавлены.

Native: собран и запущен debug Tauri `app.port.cms-qa` с отдельным свежим каталогом
`C:\PORT\.local\stage18b\app-data`. Проверены все шесть экранов на трёх размерах,
enabled CTA, реальные maximize/restore (1920×1032), gallery/Escape, отсутствие
WEB PREVIEW и горизонтального переполнения, reduced-motion диалог на 800×600 и
solid fallback. JS-ошибок нет; installation registry и история загрузок пусты.

TypeScript/frontend build проходят. Сохраняется предупреждение Vite о JS chunk
больше 500 kB. Целевые UI-проверки и 9 Rust `hub_download` regression tests проходят;
точное количество финальных UI-тестов записано в PROGRESS.md.

Новая реальная передача архива, destination picker/no-clobber и запуск игры для этой
визуальной задачи не выполнялись. Native screenshot не доказывает GPU-производительность
на всех устройствах, OS DPI или полное WCAG соответствие. Не менялись Rust-загрузчик,
SQLite, API-контракты, пользовательские данные и legacy-движки. Исходные dirty файлы
сохранены отдельно от коммита. Push, deploy, release и installer не выполнялись.

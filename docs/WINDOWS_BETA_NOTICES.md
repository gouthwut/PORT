# PORT local Windows beta candidate

Local acceptance only. Not authorized for publication or redistribution.

PORT source is MIT (included as PORT-LICENSE.txt). Inter and Manrope are
unmodified SIL OFL 1.1 fonts; their full notices accompany this candidate.
The geometric PORT icon is original project artwork. The Home illustration
src/hub/assets/hub-hero.webp is original generated PORT brand artwork; provenance
and the original prompt are recorded in docs/HUB_HOME_REVIEW.md.

Game media is fetched from the configured CMS, never packaged from the local QA
cache. Publication requires a separate rights review of every published CMS
image. No redistribution permission for private Bloodborne art is established;
it is excluded from this candidate. The optional local LGPL-3.0 PKG worker is
also excluded. Existing installation records and game files are not packaged.

JavaScript and Rust dependency metadata inventories exist in docs/licenses/.
They are not a complete binary-distribution notice bundle. Full third-party
license/NOTICE texts and attribution review remain a public-release blocker.
This installer does not grant rights to any console game, trademark or runtime.

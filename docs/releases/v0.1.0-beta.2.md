# PORT Beta 2 (v0.1.0-beta.2)

Welcome to the second public beta release of **PORT**!

PORT is an open-source Windows catalog and download manager for independently developed PC ports, static recompilations, decompilations, and compatibility runtimes.

## Highlights in Beta 2

- **Automatic Catalog Updates:** Seamless catalog synchronization on startup, window refocus after being idle, and network reconnection, with full manual refresh capability preserved.
- **Offline Resilience & Caching:** Persistent local cache retains previously verified catalog entries if CMS is temporarily unreachable or when launching offline.
- **Production Signed Auto-Updater:** Official Tauri updater integration backed by GitHub Releases and cryptographically verified Minisign signatures, enabling seamless updates across beta versions.
- **Security Hardening:** Pruned deprecated legacy IPC commands and internal development artifacts from the public distribution.
- **Automated Dependency Auditing:** Added Dependabot configuration for continuous security updates across npm and Cargo packages.

## Installation Instructions

1. Download `PORT-Setup-0.1.0-beta.2.exe` from the assets below.
2. Run the installer (installs for current user; no admin permissions required).
3. If you have **PORT Beta 1** installed, Beta 2 will upgrade it automatically while preserving all saved preferences, favorites, and download history.

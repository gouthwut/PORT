# PORT Beta 1 (v0.1.0-beta.1)

Welcome to the first public beta release of **PORT**!

PORT is a Windows catalog and download manager for independently developed PC ports, static recompilations, decompilations, and compatibility runtimes.

## Highlights in Beta 1

- **Modern Liquid Glass Desktop Interface:** Dark theme with subtle specular reflections, compact cards, responsive layout, and smooth transitions.
- **Dynamic Cloud Catalog Integration:** Real-time synchronization with the official Cloudflare API v2.
- **Direct GitHub Release Downloads:** Stream official Windows builds directly inside PORT with live progress, speed indicators, pause/cancel, and retry support.
- **Integrity Verification:** Automated SHA-256 hash checks for release archives when hashes are available upstream.
- **Safe File Management:** Destination picker, overwrite prevention, download history tracking, and one-click "Open folder" access in File Explorer.
- **5 Supported Languages:** Fully localized in English (default), Russian, Spanish, French, and German.
- **100% Client-Side Privacy:** No telemetry, tracking, or required user accounts. All preferences and history remain stored locally in SQLite.

## Installation Instructions

1. Download `PORT-Setup-0.1.0-beta.1.exe` from the assets below.
2. Run the installer (installs for the current Windows user without requiring admin rights).
3. Launch **PORT** from your Start menu or desktop shortcut.

## Note on Catalog Content

In this initial Beta 1 release, the public catalog starts empty as the owner prepares and verifies upstream port entries. New verified community ports, recompilations, and official builds will appear automatically in the app without requiring an update.

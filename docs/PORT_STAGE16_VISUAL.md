## Материалы и визуальное решение

Найден `design/references/референс.zip` и распакованный
`design/references/PORT-HUB-Design-Pack/`. Основной источник —
`boards/00-ORIGINAL-APPROVED-STYLE.png`; просмотрены оригинальные Home, Catalog и
Project. `сейчас.rar` отсутствует в существующих каталогах референсов; вместо него
снята исходная версия приложения до изменения исходников.

[RecompLauncher](https://recomplauncher.com/) изучен как дополнительный ориентир
структуры поиска, каталога и страниц проектов. Его код, брендинг, проекты и
изображения не импортировались. Основной визуальный ориентир — PORT board.

- Home: сокращён hero, усилен контраст, сохранена янтарная CTA. Компактные
  платформы без повторения названия консоли. Под hero видны реальные обложки.
  Заголовок «Проекты» не приписывает каталогу редакционный отбор.
- Catalog: удалён декоративный баннер. Фильтры в колонке 196 px; до 1050 px —
  доступная раскрываемая панель с индикатором активного фильтра. Поиск, сортировка
  и сетка находятся рядом. Вертикальные карточки ограничены по ширине; два
  проекта не растягиваются на весь экран. Убрана техническая строка «API v2».
- Project: читаемый заголовок, платформенные/технологические бейджи, янтарная
  доступная native CTA, версия и размер. Качественный широкий CMS-кадр допускается
  при ширине от 1440 px и соотношении 1.6–2.5, отображается шириной до 860 px.
  Иначе справа показывается ограниченная обложка на тёмном атмосферном фоне.
  Маленькие gameplay-кадры не становятся растянутым hero. Галерея горизонтальная;
  навигация ведёт к существующим разделам и раскрывает закрытую инструкцию.
  Нет пустых вкладок, оценок и выдуманной совместимости.
- Sidebar: 198 → 156 px, collapsed — 56 px. Сохранён PORT//; повторный текстовый
  бренд в titlebar скрыт. Декоративный картридж уменьшен, в узком режиме убран.
- Downloads: короткое пустое состояние с переходом в каталог; компактные строки
  истории. Settings: секции разумной ширины и более плотные строки. Переключатель
  компактных карточек применяется и к актуальным сеткам Hub.

Исходная оригинальная иллюстрация PORT осталась декоративным Home artwork.
Игровые обложки и скриншоты получены через проверяемые CMS media; новые изображения
не генерировались, в Git игровой artwork не добавлен.

## Проверки и границы

PASS: TypeScript и Vite build (сохранено прежнее предупреждение JS bundle >500 kB),
45 актуальных Playwright-проверок, 9 Rust hub_download regression tests,
форматирование изменённых файлов и git diff --check. Проверены все четыре языка
до 320 px; 125/150% device scale — симуляция браузера, не Windows DPI.
Старые v1/installer UI suites не запускались как тесты текущей навигации.

Реальный Tauri debug собран и запущен с identity app.port.cms-qa и свежим
хранилищем C:/PORT/.local/stage16/app-data; installation registry пуст.
Native скриншоты — native-replay-after-*.png, отдельный native-replay-geometry.json.
Проверены Home, Catalog, Zelda, Sonic, пустые Downloads и Settings на 1280×720 и
800×600, enabled янтарная CTA, gallery/Escape, реальное maximize/restore;
развёрнутый WebView — 1920×1032. Начатых загрузок и JS-ошибок — ноль.
Данные для native-отрисовки — сохранённые реальные публичные CMS ответы, через
QA-маршрутизацию запросов WebView; native IPC и SQLite остаются настоящими.
Это проверка native UI, а не новая live HTTPS/ZIP проверка.

Локальный публичный CMS работал при съёмке исходной версии и ответил двумя
проектами, но остановился к native QA (connection refused, localhost:8787).
Владелец подтвердил параллельную доработку CMS и явно разрешил продолжение по
сохранённым данным/fixtures без ожидания live API. Соседние репозитории для его
перезапуска не открывались. Production 401 не
обходился; аутентификация, TLS, CSP и production permissions не менялись.
Для задания размера окна временное разрешение allow-set-size находилось только
в ignored .local/stage16/*.json конфигурации QA.
Предыдущие native picker/transfer/Snap/OS-DPI ограничения Stage 15F сохраняются.
Строки истории проверены browser mock-тестами; свежая native QA история пуста.
После финальной съёмки QA-приложение и debug listener закрыты.

Все 50 снимков доступны в локальном [индексе сравнений](../.local/evidence/16-visual/INDEX.md).

Rust downloader, CMS/API v2, Tauri production permissions/config, SQLite-схемы и
legacy-движки не изменялись. История не удаляет файлы, native остаётся единственным
источником фактического пути. Сохранены один активный download, version/approval/
availability guards, выбор папки и no-clobber, запрет автозапуска/установки и
семисекундный таймер уведомления с паузами. Новая передача ZIP для этой визуальной
задачи не требуется; приёмка реальных picker/transfer из Stage 15F не повторяется.

Предыдущие грязные Cargo/image, InstalledLibrary, stage04d и untracked owner

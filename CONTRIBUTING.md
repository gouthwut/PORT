# Contributing

Read AGENTS.md, PROGRESS.md and ROADMAP.md first. Stage 02 needs explicit project-owner authorization. Use a focused branch and describe user-visible behavior and validation in each PR.

Windows setup and checks are in README.md. Run frontend build, Playwright, Rust formatting/tests and native Tauri build for relevant changes. Inspect real screenshots and test native IPC after backend changes; browser tests alone do not validate Windows.

Do not submit game files, dumps, PKG, upstream GPL implementation code, proprietary artwork, credentials or generated build directories. Respect the independent authors of every port. New adapters need dated primary-source research and reviewed compatibility/redistribution requirements. Keep docs and progress honest about untested features.

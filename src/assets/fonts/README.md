# Bundled typefaces

Unmodified variable fonts, embedded locally. No font requests are made at runtime.
Both families include Cyrillic and Latin glyphs and permit application embedding
under the SIL Open Font License 1.1. Keep their individual license notices with
redistributions; PORT's MIT license does not replace them.
